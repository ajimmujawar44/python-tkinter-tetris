# Puzzle Block Game 🎮

A classic Tetris-style puzzle game built with Python and Tkinter. Stack falling blocks, complete lines, and achieve high scores!

![Puzzle Block Game](screenshots/demo.png)

## Features ✨

- **7 Classic Tetromino Shapes**: I, O, T, S, Z, J, L pieces with distinct colors
- **Line Clearing**: Complete horizontal lines to clear them and score points
- **Score Tracking**: 100 points per line cleared
- **Game Controls**: Intuitive keyboard controls for movement and rotation
- **Game States**: Start, Pause, and Reset functionality
- **Game Over Detection**: Automatic game over when blocks reach the top

```bash

```

2. No additional dependencies required! Tkinter comes pre-installed with Python.

## Usage 🎯

### Running the Game

```bash
python puzzle_block_game.py
```

Or if you're using Python 3 specifically:

```bash
python3 puzzle_block_game.py
```

### Controls

- **← (Left Arrow)**: Move piece left
- **→ (Right Arrow)**: Move piece right  
- **↓ (Down Arrow)**: Drop piece faster
- **↑ (Up Arrow)**: Rotate piece

### Game Buttons

- **Start Game**: Begin a new game
- **Pause**: Pause/Resume the game
- **Reset**: Clear the board and start over

## How to Play 🎲

1. Click "Start Game" to begin
2. Use arrow keys to move and rotate falling blocks
3. Complete horizontal lines to clear them and score points
4. Try to get the highest score before the blocks reach the top!

## Scoring 💯

- **1 line cleared**: 100 points
- **2 lines cleared**: 200 points
- **3 lines cleared**: 300 points
- **4 lines cleared (Tetris!)**: 400 points
