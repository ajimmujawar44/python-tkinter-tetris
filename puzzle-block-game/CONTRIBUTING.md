# Contributing to Puzzle Block Game

Thank you for your interest in contributing to the Puzzle Block Game! This document provides guidelines and instructions for contributing.

## How to Contribute

### Reporting Bugs

1. Check existing issues to avoid duplicates
2. Create a new issue with:
   - Clear title and description
   - Steps to reproduce the bug
   - Expected vs actual behavior
   - Your system information (OS, Python version)

### Suggesting Features

1. Check existing feature requests
2. Create a new issue with:
   - Clear description of the feature
   - Use cases and benefits
   - Possible implementation approach

### Submitting Code

1. Fork the repository
2. Create a new branch for your feature:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Make your changes following the code style
4. Test your changes thoroughly
5. Commit your changes:
   ```bash
   git commit -m "Add your feature description"
   ```
6. Push to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
7. Create a Pull Request

## Code Style Guidelines

- Follow PEP 8 style guidelines
- Use meaningful variable and function names
- Add docstrings to functions and classes
- Keep functions focused and modular
- Add comments for complex logic

## Testing

- Test your changes on different platforms (Windows, Mac, Linux)
- Ensure the game runs without errors
- Test all game features (start, pause, reset, controls)
- Verify no memory leaks or performance issues

## Feature Ideas

Here are some potential features you could contribute:

- Next piece preview
- Hold piece functionality
- Increasing difficulty levels
- High score tracking with local storage
- Sound effects and music
- Different game modes (sprint, marathon)
- Multiplayer support
- Custom themes and colors
- Mobile touch controls
- Leaderboard system

## Questions?

Feel free to open an issue for any questions about contributing!
