# Screenshots

This folder should contain screenshots of the game for the README.md file.

## Required Screenshots

1. **demo.png** - Main demo image for the README header
2. **gameplay.png** - Screenshot of active gameplay
3. **gameover.png** - Screenshot of the game over screen

## How to Add Screenshots

1. Run the game: `python puzzle_block_game.py`
2. Take screenshots during gameplay using your OS screenshot tool:
   - **Windows**: Win + Shift + S (Snipping Tool)
   - **Mac**: Cmd + Shift + 4
   - **Linux**: PrtScn or use screenshot tool
3. Save images in this folder with the names above
4. Update the README.md image links if filenames differ

## Tips for Good Screenshots

- Use high resolution
- Show the game window clearly
- Include UI elements (score, buttons)
- For gameplay: show blocks falling and lines being cleared
- For game over: show the "GAME OVER" text and final score
